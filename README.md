# 住区蚊媒监测与智能预警平台

面向珠实住区试点。PC 管理端重点支持蚊媒监测和风险预警，移动处置端支持接单、现场记录和上报。

## 目录与主责

| 目录 | 主责 | 范围 |
| --- | --- | --- |
| `frontend/web-admin/` | A · 前端 | PC 管理端，负责监测总览、趋势、地图图层渲染和预警详情 |
| `frontend/mobile-app/` | A · 前端 | 移动处置端，负责接单、现场记录和结果上报 |
| `backend/app/`、`backend/migrations/` | B · 后端 | 设备与文件接入、原始记录、权限、业务 API、数据库迁移、预警与任务流转 |
| `gis/` | C · GIS 与数据 | 底图和点位加工、坐标与区域编码、空间分析、数据清洗与图层产出 |
| `models/` | C · 算法与建模 | 密度预测、风险分级算法、模型评估与版本记录 |
| `docs/` | 三人共用 | 需求、架构、指标口径及与 CDC 共同确认的分级分区处置规则 |
| `interfaces/` | B 维护，A 与 C 共同评审 | 前后端 API、GIS 图层规范、模型输入输出 |
| `deploy/` | C 主责，B 配合 | 平台部署、服务配置模板和运行说明 |
| `tests/` | 三人共用 | 接口联调及监测、预警、处置、复核的端到端验证 |

## 模块交接

- B 提供可追溯的原始数据，C 提供质量校验、分析图层及模型结果。B 通过统一业务 API 发布，A 负责页面呈现和地图交互。
- 联调先约定点位和区域标识、坐标参考系、采样时间与单位。模型结果注明实测或预测、适用时段及版本，前端在地图上区分实测与预测。
- C 提供风险结果及依据，B 根据确认的规则维护预警和任务流程。处置措施按风险等级与区域类型匹配，具体规则由项目组与 CDC 共同确认。
