# 蚊媒监测 Demo

包含设备总览、驾驶舱、居民提示，以及用 7 个模拟点位验证的 CSV 入库、分层统计和预警。

## 启动快照预览

需要 Python 3.10 或更新版本。在仓库根目录运行：

```text
python -B demo/蚊媒数据入库/demo_server.py --snapshot
```

- [驾驶舱小时趋势、地图和预警](http://127.0.0.1:8765/?hourly=1)
- [点位 7 日统计](http://127.0.0.1:8765/#point7-daily)
- [居民时段提示](http://127.0.0.1:8765/蚊媒监测平台-居民首页.html)

快照包含 2026 年 11 月 1–2 日的模拟统计。后台导入、增量刷新和定时扫描见[运行说明](./蚊媒数据入库/README.md)，按部署环境调整 Python、psql 和数据库路径。演示阈值用于联调。
