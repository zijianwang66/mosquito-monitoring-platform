# 蚊媒监测平台数据库运行验收报告

验收日期 2026-11-14。使用临时 PostgreSQL 16.15 实例、QGIS 附带的 psql、Python 3.12 和 Flask 测试客户端。实例仅监听本机随机端口，测试结束后已关闭。全部输入为临时生成的模拟 CSV，未连接生产库。

## 验收结果

| 场景 | 实测结果 | 判定 |
| --- | --- | --- |
| 从空库部署 | 依次应用 `schema.sql` 与 `001` 至 `003` 迁移，CLI 可入库，Flask 可读取 OPS 记录 | 通过 |
| 正常入库与同批重跑 | 两次处理关联同一个文件批次，标准观测仍为 2 条 | 通过 |
| 迟到观测 | 同小时补入 40 后，应用小时视图返回新峰值 40 | 通过 |
| 读数冲突 | 同设备同时间重传不同读数，CLI 返回 2，质量报告记录 1 条冲突 | 通过 |
| 指标缺测 | 一个分类计数留空，分类计数与派生总数共计 2 个缺测值，CLI 返回 2 | 通过 |
| 文件异常与恢复 | 错误表头返回 1，OPS 留下未关联批次的失败运行。随后重跑有效文件成功 | 通过 |
| 更正与删除后的对账 | 将峰值从 40 改为 12，并删除另一小时的最后一条观测。报告发现日汇总差异及 2 个小时汇总差异 | 检测通过，修复待实现 |
| 监控读取 | Flask 使用实际 psql 读取临时实例，运行列表返回分页游标，详情包含任务和质量结果，失败过滤返回异常运行 | 通过 |
| 浏览器联调 | Chrome 在 1280px 和 360px 视口经本机 Flask HTTP 服务读取临时 PostgreSQL，核对失败筛选、失败原因和对账结果，页面无横向溢出。分页另经模拟响应和真实 API 验证 | 通过 |

## 结论与待验收项

模拟 CSV 经 Python 和 psql 入库并生成 OPS 质量报告，浏览器通过 Flask API 查询同一测试库。完整链路通过本地验收。

更正和删除会触发对账差异，系统仍需受控重算和清理空分组的流程。异常恢复验证覆盖修正输入后重跑。生产角色权限、调度、并发性能、备份恢复与生产结构差异均待上线前验证。
