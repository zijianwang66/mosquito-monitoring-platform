# 移动端页面原型

直接用浏览器打开任一 HTML 文件即可预览。页面为静态原型，使用演示数据。

| 文件 | 内容 |
| --- | --- |
| [蚊媒监测驾驶舱.html](蚊媒监测驾驶舱.html) | 当前居民版入口，包含虚拟播报员、风险场景切换、场地图和 1 米网格样例 |
| [蚊媒监测平台-居民首页.html](蚊媒监测平台-居民首页.html) | 早期居民首页 |
| [蚊媒监测平台-竖版首页.html](蚊媒监测平台-竖版首页.html) | 监测总览与趋势原型 |
| [住区蚊媒空间估算-demo.html](住区蚊媒空间估算-demo.html) | 可输入设备读数的空间估算演示 |

页面的样式和脚本写在各自的 HTML 里。修改居民版时，保持 `住区播报员.webp` 与入口 HTML 同目录。该头像为生成的虚拟人物插画。

居民版场地图依据景观施工图截图重绘，点位和风险等级均为示例。接入实际场地前需核对地图比例、设备坐标与风险评估规则。
